# 정책 차단 / 원인 미확정 차단 분리 재집계 (2026-11-18)

- 판정 엔진 v2.2, 파라미터, 기록, 난수 시드는 그대로. 엔진이 이미 남기는 note=unmodeled_policy(가설로 설명되지 않는 차단에 붙인 정책 판정)만 읽어 "원인 미확정 차단"으로 나눠 보고한다. 판정 규칙의 변경이 아니라 보고 범주의 변경이다.
- Python 3.9로 실행(원래 결과와 같은 버전). Python 3.12 이상에서는 실수 합 계산 방식 차이로 q=0.01 재판정 15,300건 중 1건(vaultwarden-1.35.5-synced)이 유보→차단 없음으로 달라진다.
- 변경 전 값(9,344 / 5,868 / 5,416 / 1,482 / 101·66 / 62·21 / 3.9% / 11.0%)이 그대로 재현됨을 확인한 뒤 새 값을 계산했다.
